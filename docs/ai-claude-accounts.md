# Claude 멀티 계정

AionUi 개인 fork는 한 PC에서 Claude 구독 계정을 여러 개(예: 회사 Team과 개인 Max) 사용할 수 있다. 계정 준비, 로그인, 지침·스킬 공유, AionUi 등록은 AionUi fork 저장소의 [`docs/guides/claude-accounts.md`](https://github.com/mabobsa/AionUi/blob/main/docs/guides/claude-accounts.md)를 따른다.

MindNProgress는 AionUi가 정한 계정 목록과 번호를 그대로 사용한다. MnP가 따로 저장하는 것은 대화 용도별 기본 계정(역할 정책)뿐이다.

**계정이 1개면 기존과 똑같이 동작한다.** 대화 창에 계정 선택이 나타나지 않고, AionUi 요청에 계정 값을 넣지 않으며, 작성자 표기에도 번호를 붙이지 않는다.

## 계정 목록과 번호

- 실행 머신별로 AionUi 관리 에이전트 목록의 Claude Code 항목에서 계정 목록을 읽는다. AionUi는 계정이 2개 이상일 때만 목록을 제공한다. 서브 머신에서 실행하는 대화는 그 머신의 계정 목록을 사용한다.
- 번호는 AionUi 설정 화면의 계정 순서다. 화면에는 ①…⑳으로, 21번부터는 `#21`로 표시한다.
- 기본 계정은 AionUi의 기본 Claude 설정 폴더 계정이다. 계정을 지정하지 않은 대화는 이 계정으로 실행된다. 순서를 바꾸지 않았다면 1번이다.

## 역할 정책: 용도별 기본 계정

대화 용도를 두 가지 역할로 나누고, 역할마다 기본 계정을 하나씩 저장한다.

| 역할 | 대화 용도 |
| --- | --- |
| 그룹 총괄 대화 | 그룹 총괄(`group-coordination`) |
| 문서·카드 대화와 AI 위임 | 문서·카드 대화, Dooray 응답, 카드 배치, 문서 재구성, 공유 지식 검토, AI가 만드는 위임·그룹 지시 대화 |

- 정책은 실행 머신별로 MnP 데이터 폴더의 `_ai-claude-account-policy.json`에 저장한다.
- 정책은 **AI 대화 시작** 창에서 정한다. Claude 계정을 고르고 `이 계정을 …의 기본 계정으로 사용`을 체크한 뒤 대화를 시작하면 저장된다. 고른 계정이 이미 그 역할의 기본 계정이면 체크 상자 대신 안내 문구가 나온다.
- 예: 총괄은 Team, 나머지는 Max로 쓰려면, 그룹 총괄 대화를 시작할 때 ① 회사 Team을 고르고 체크한다. 카드 대화를 시작할 때는 ② 개인 Max를 고르고 체크한다.

## 대화별 계정 결정 규칙

| 대화 | 계정 결정 순서 |
| --- | --- |
| 사람이 **AI 대화 시작** 창에서 시작 | 창에서 고른 계정. 창의 초깃값은 직접 고른 계정 → 용도의 정책 계정 → 목록의 첫 계정 순이다. 사람이 고른 계정이 정책보다 우선한다. |
| AI가 만드는 위임·그룹 지시 대화 | 이번 요청에 명시한 계정 → '문서·카드 대화와 AI 위임' 정책 계정 → 같은 AI 종류의 최근 대상·상위 대화 계정 → 기본 계정 순이다. |
| Dooray 응답 대화 | Dooray 응답 설정에 저장한 계정 → '문서·카드 대화와 AI 위임' 정책 계정 → 기본 계정 |

- 목록에 없는 기본값(삭제된 계정 등)은 무시하고 다음 순서로 넘어간다. 위임·그룹 지시에서 명시한 계정이 없으면 다른 계정으로 대체하지 않고 생성 전에 오류를 반환한다.
- 대화를 만든 뒤에는 계정이 바뀌지 않는다. 한도에 걸린 계정 대신 다른 계정을 쓰려면 새 대화를 시작한다.
- 카드에 연결한 대화 기록은 계정을 함께 보존한다. AionUi 대화에서 연결을 복원할 때도 대화의 계정을 읽어 온다.

### 이번 위임의 계정 지정

`mindnprogress_delegate_ai_work`와 `mindnprogress_send_group_document_instruction`의 `strategy=new`에서 `newConversation.claudeAccountNumber`(예: `1`) 또는 `newConversation.claudeAccountId` 중 하나를 지정한다. 사용자가 이번 작업의 계정을 요청했을 때 사용하며, 번호는 실행 머신의 최신 관리 목록에서 ID로 변환한다. 계정 순서를 바꿀 수 있으므로 1번을 무조건 `default`로 추측하지 않는다. 단일 계정 환경은 1번 또는 `default`를 지원한다.

명시한 계정은 이번 새 대화에만 적용되고 용도별 기본 정책은 바뀌지 않는다. 두 항목을 함께 지정하거나 Claude가 아닌 AI에 지정하면 거부한다. 기존 대화를 이어가는 `resume`에서는 계정을 바꿀 수 없으므로 계정 지정 시 새 대화를 요청하도록 안내한다. 같은 중복 방지 키로 계정만 바꾼 재요청도 별도 요청으로 구분해 거부한다.

## 화면 표시

- **AI 대화 시작:** AI 종류가 Claude Code이고 계정이 2개 이상이면, AI 종류 칸의 오른쪽 절반에 `Claude 계정` 선택이 나타난다.
- **Dooray 응답 설정:** 같은 조건에서 `Claude 계정` 선택이 나타나며, 고른 계정을 설정에 저장한다.
- **대화 선택 창:** 카드에 연결된 대화마다 `② 개인 Max`처럼 계정 번호와 이름을 표시한다.
- **작성자 표기:** AI가 남긴 댓글과 변경 이력의 작성자에 `Claude Code ②(Opus)`처럼 계정 번호를 붙인다. 순서를 바꿔도 이미 기록된 표기의 번호는 바뀌지 않는다.
- **구독 사용량:** 상단에는 사용량이 가장 높은 Claude 계정 하나만 표시한다. 기준은 5시간·주간 사용률 중 높은 값이고, 값이 같으면 번호가 앞인 계정을 고른다. 마우스를 올리면 툴팁에 전체 계정의 사용량이 나온다. 모바일 상세 창은 계정별로 나눠 표시한다. MCP `mindnprogress_get_ai_usage` 결과에도 `claudeAccounts`로 계정별 값이 포함된다.

## 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| 계정 선택이 나타나지 않음 | AionUi에 계정이 2개 이상 등록돼 있는지, 선택한 AI 종류가 Claude Code인지 확인한다. 서브 머신 대화라면 그 머신의 AionUi 등록 상태를 본다. |
| 위임 대화가 예상과 다른 계정으로 실행됨 | 이번 새 대화의 계정 지정이 있는지 확인한다. 생략했으면 '문서·카드 대화와 AI 위임' 정책이 상위 대화의 계정보다 우선한다. |
| 사용량 툴팁에 계정 값이 없음 | AionUi는 각 계정의 최근 대화 작업 공간에서 사용량을 조회한다. 그 계정으로 대화를 한 번 시작한 뒤 다음 갱신(약 2분)을 기다린다. |
| 두 번째 계정에 MnP 스킬이 없음 | 설치기는 기본 Claude 폴더에만 스킬을 설치한다. 아래 설치기 안내를 따른다. |

## MnP Suite 설치기와 두 번째 계정

Windows·macOS 설치기는 스킬과 관리 블록을 `CLAUDE_CONFIG_DIR`(없으면 `~/.claude`) 한 곳에만 설치한다. 두 번째 계정 폴더에는 설치 후 다음을 직접 준비한다.

- `<두 번째 계정 폴더>/CLAUDE.md`에 `@~/.claude/CLAUDE.md` 한 줄만 둔다. 기본 폴더의 지침(MnP Suite 관리 블록 포함)을 가져온다.
- `mnp-dooray`, `mnp-spec-driven-development`처럼 설치된 스킬 폴더를 `~/.claude/skills`에서 `<두 번째 계정 폴더>/skills`로 복사한다. 설치기를 다시 실행해 스킬이 바뀌면 다시 복사한다.
- `CLAUDE_CONFIG_DIR`를 두 번째 계정 폴더로 지정한 채 설치기를 실행하지 않는다. 가져오기 한 줄만 둔 `CLAUDE.md`에 관리 블록이 병합되어 지침이 두 번 들어간다.
