`npm run build`와 `npm run lint`를 격리 후보에서 다시 실행해 모두 종료 코드 0이다. 기존 브라우저 시험의 no-unsafe-finally 경고 1건과 번들 크기 경고는 남는다. 새 07 시험 3개에는 lint 경고가 없다.

### 초기 시도와 제한 보존

- `browser-01`은 MnP 웹 로그인이 필요한 승인 목록에 MCP 인증만 사용해 401이었다. 합성 편집자의 실제 로그인 쿠키를 사용하도록 시험을 보완했다.
- `browser-02`는 새 페이지 초기 주입에 의존한 pending fixture가 준비되지 않았다. 실제 App 준비 후 같은 sessionStorage를 넣도록 시험 순서만 보완했다.
- `browser-03`의 일반 재확인은 통과했고 재시작 사례는 임시 로그인 세션 소멸로 401이었다. 기존 로그인 유지(`rememberMe`) 계약으로 실행한 `browser-04`는 2/2 통과했다. 인증 만료를 승인 완료로 우회하지 않으며 로그인 유지가 아니면 재로그인이 필요하다. 제품 변경은 하지 않았다.
- 이 세 실행의 실패 로그·화면·소스 해시를 보존한다. 최초 07의 잠금 시간 초과와 단독 재통과, 최초 조회·영속 쓰기·일부 CPU/RSS 비용 증가도 그대로 유지한다.
- 전체 부하·성능 비교, 원래 MCP 60개 도구 전체, 실제 AionUi·Dooray·Runner·push, 운영 데이터·재시작·배포는 이번에 다시 실행하지 않았다. 기존 통과 근거 재사용과 미실행을 구분한다. 새 부하 수치나 외부 연동 완료를 주장하지 않는다.
